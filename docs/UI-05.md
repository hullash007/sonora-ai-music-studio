# UI05:workspace backup and restore

Local-only increment after verified UI04 release. No backend, infrastructure, Modal or generation changes.

Settings offers a JSON backup of the current composition, drafts, projects, preferences and active-project reference. The versioned envelope has a timestamp; exports exclude server/auth/audio/jobs/credits. Backups may contain personal creative text and should be kept safely.

Pure module validates the whole file before preview;5 MiB/10,000 record limits, strict types/ranges/identities, unsupported schema and unfamiliar fields rejected clearly instead of silently discarded. Known legacy brief fields receive additive defaults. Manual engine prompts remain untruncated, including overlimit prompts. Existing field limits are validated before normalization to prevent truncation. Emoji and multiline lyrics round-trip.

Merge is default:current editor/preferences/project context remain, imported records added, equivalent content deduplicated and conflicting IDs remapped. Imported editor becomes a draft; repeated imports are idempotent. Replace requires explicit mode selection plus acknowledgment and a separate action. Cancel/file-read races cannot commit data.

Import persists the complete candidate atomically before changing live React state or announcing success. Storage failure leaves existing bytes and session content unchanged with a warning. Blocked storage permits session export but import cannot claim completion without a successful save. Automatic saving is suppressed after known unavailable/malformed storage, preserving existing raw content. An explicit restore persists the editor once even when restored remember-editor preference is false; subsequent edits still respect that preference.
