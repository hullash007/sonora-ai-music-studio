# Google studio release

This source snapshot includes Google sign-in, account-owned libraries, guarded shared generation and the music-first customer UI. It is published as a separate release branch; main is unchanged.

The deployed profile offers fixed 30, 60, 90 and 120-second MP3 generation choices. Live end-to-end checks verified 30 and 120 seconds; 60 and 90 have offline parameter, admission, media-gate and UI checks but no separate live model runs. Configure SONORA_VALIDATED_DURATIONS explicitly for the durations you have accepted in your deployment; the safe source default remains 30. Keep SONORA_OWNER_VALIDATE_120 disabled outside a bounded owner verification. The simplified interface uses true-blue accents, a slightly deeper warm-gray canvas and light cards. The core path is description, length, vocals, generate, then inline playback/download. Optional sound preferences, drafts, templates and arrangement/prompt tools are collapsed rather than removed. Desktop top navigation and phone bottom navigation provide access to library, projects and settings. Sound and arrangement controls are prompt preferences, not audio-editing guarantees. No model weights, audio, credentials, account data or private execution records are included.

Deployment-specific identity values are supplied through SONORA_GOOGLE_CLIENT_ID, SONORA_OWNER_EMAIL, SONORA_ARCHIVE_GUARD, SONORA_ARCHIVE_RUN_ID and SONORA_ARCHIVE_JOB_ID. Archive settings preserve an existing deployment's track history. Configure a real privacy contact before deployment. Resource names, image/checkpoint pins and budget constants in the example adapters must be reviewed for your own deployment. Do not deploy this sanitized snapshot over a running studio without restoring its deployment configuration.

Local tests: PYTHONPATH=backend python -m unittest discover -s tests. Frontend: cd frontend && npm ci && npm test && npm run build.
