# UI-01 - design system and responsive shell

## Implemented locally

- React/Vite source under frontend, pinned dependency lock, compiled assets committed under backend/sonora/static. No CDN, remote fonts or analytics.
- FastAPI delivers the built index and only two exact asset paths. Public method/route allowlist and noindex headers preserved. Authenticated mode holds its password in memory, not persistent storage.
- Studio: title, composition brief, style direction, duration, instrumental/lyrics selection, local drafts.
- Library: real API, search/sort, playback with seek/pause, download, honest empty/error/loading states. No fake tracks.
- Projects: browser-local create/rename/open/delete. Project brief changes persist locally.
- Settings: persistent local preferences, reduced motion, compact library, autosave choice.
- Hash navigation and back/forward; full sidebar, tablet icon rail and mobile bottom navigation. Versioned storage, visible per-browser scope and unavailable-storage fallback.

## Verification

- 135 Python tests under 3.10/3.12.15; PowerShell/compile pass (Linux, Windows not tested).
- Production build: JS about 244kB (76kB gzip), CSS about 20kB (5.4kB gzip). npm audit reports no production vulnerabilities at check time.
- Browser: 1440/1024/768/390/320px, no horizontal overflow or JS errors. Inspected Studio desktop/mobile and Library/Projects/Settings screenshots.
- Local tests exercise draft save/load/delete, project create/rename/open/delete, preferences/reload, browser back/forward, unavailable storage.
- Separate synthetic local WAV fixture verifies authenticated password error/success, library search, play/pause/seek/download (88,244 bytes), no JS errors. The fixture was not copied to live staging or presented as generated music.
- All local workspace actions made no API mutations. Public preview engine remains disabled.

## Scope

Local implementation only. Live preview remains the previous verified basic UI until a later reviewed UI deployment. No Modal/GPU/model/card calls for this increment. Existing API behavior and production resources unchanged. Old HTML string removed; Python checkout includes built UI assets.
