# UI-02: Composition Brief Builder

Browser-local only. This increment does not change any API route, worker, generation guard, model setting or infrastructure. No generation is connected, no audio is fabricated, and no GPU/Modal call is made.

## Workflow

- Idea: working title, creative description and optional free-text reference.
- Sound: separate style and emotion, energy slider, tempo intention, optional validated 50-200 BPM.
- Arrangement: multi-select instruments, instrumental/vocal mode. Switching to instrumental hides but retains lyrics. Vocal direction and language are optional.
- Details: 30/60/90/120-second intent, production notes limited to500characters.
- Review: deterministic live brief, copy to clipboard with selectable-text fallback, save complete independent snapshots, confirmed clear that preserves saved drafts.

The extra controls express creative preferences, not guaranteed model parameters. The existing {prompt, lyrics, duration} generation contract is untouched.

## Storage

The existing sonora.workspace.preview.v1 key and version remain. normalizeBrief supplies additive defaults to the editor, every draft and every project's brief. Existing IDs, timestamps and style values survive. Numbers and arrays are checked; unknown malformed workspace data uses the explicit in-memory fallback. Saving project edits retains all extended fields. There is no cloud sync claim.
