# UI-03: Deterministic Prompt Builder

Local-only bridge from the human composition brief to a preview of the unchanged {prompt, lyrics, duration} contract. No LLM, network request, generation, infrastructure change or deployment.

## Behaviour

- Compiler preserves the original description first, then adds style/emotion, instruments, energy/tempo, mode-appropriate vocal direction/language, and production notes in a fixed order.
- Creative reference is excluded by default and included only by an explicit checkbox.
- Lyrics stay separate. Instrumental preview payload contains empty lyrics and no compiled vocal directions. Manual prompt text is the user's own text and is never silently rewritten.
- Before manual editing, the prompt follows the brief. Editing freezes the prompt. Changes to its composition show a stale notice; explicit rebuild offers keep/replace confirmation for manual edits.
- A prompt longer than512characters remains intact, persists, and shows the exact overage. Copy of raw prompt remains possible; engine-input JSON copy is disabled while invalid. No truncation.
- Clipboard copy has an explicit selectable-text fallback.
- Six original templates populate only brief fields. Gallery starts collapsed. Applying offers cancel, save current snapshot then apply, or replace current editor. Existing snapshots are not deleted.
- Prompt edits/options live inside each brief, so draft snapshots and projects keep independent prompt state. Active project association now also survives reload, fixing a prior missing association while keeping existing storage key/version.
- Jump link reaches the builder without scrolling past the whole editor. Desktop/tablet/mobile layouts remain responsive.
